La programación web ha evolucionado enormemente en las últimas décadas. Lo que antes eran simples páginas estáticas con texto e imágenes se ha convertido en aplicaciones complejas e interactivas que funcionan directamente en el navegador, sin necesidad de instalar nada en el ordenador del usuario.

JavaScript es el lenguaje que permite dar vida a las páginas web. Gracias a él es posible reaccionar a las acciones del usuario, como pulsar un botón, escribir en un formulario o mover el ratón, y modificar el contenido y la apariencia de la página en tiempo real sin recargarla.

El DOM, o Modelo de Objetos del Documento, representa la estructura de una página HTML como un árbol de elementos. Cada etiqueta se convierte en un nodo al que JavaScript puede acceder, modificar, crear o eliminar, lo que da un control total sobre lo que el usuario ve en pantalla.

Los estilos se pueden aplicar de varias maneras: mediante hojas CSS externas, con etiquetas style dentro del documento o directamente desde JavaScript usando la propiedad style de cada elemento. Cada método tiene sus ventajas, y conviene elegir el más adecuado según las necesidades del proyecto.
